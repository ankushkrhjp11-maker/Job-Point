# Job Point - Job Portal & Agency Website

Job Point is a responsive web application designed for job seekers and agencies. It showcases agency services, expert guidance, team members, testimonials, and company statistics.

## 🚀 Features
- **Header & Navigation**: Fixed top header with custom action buttons (Register, Contact Us)
- **Services Section**: Details about agency offerings including Tax Advice, Planning & Strategy
- **Team Showcase**: Section displaying team members with social profile links
- **Testimonials & Fun Facts**: Client reviews and interactive business statistics display
- **Newsletter Subscription**: Integrated newsletter signup layout
- **Responsive Layout**: Designed using CSS and FontAwesome icons

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **Font Awesome 4.7.0** (Icons)
